## 已复现根因

`assets/interface.json`任务先应用“周期运行模式”，再应用“周期参数”。两者都覆盖`RunShortCycle.custom_action_param`，而Maa对此参数对象执行替换，不是逐字段深合并：

```text
模式覆盖后： { apply: true }
参数覆盖后： { rounds: 1, poll_seconds: 20, timeout_seconds: 900 }
```

真实Framework 5.13.1资源覆盖实验得到相同结果。Agent读取缺失的`apply`时默认false，因此工作进程进入预览，也就没有弹出清地确认框。
