# Maa 接入最小实施计划

更新：2026-10-15。原分阶段计划保留如下；最新进展：UI、Agent及实验性小麦周期工作进程已接通，UI预览通过，正式游戏周期未验收。当前用法与边界以[MAA_UI.md](./MAA_UI.md)为准。

## 已有基线

单槽小麦已实机通过：订单缺5 → 农田1一次性排产5 → 进度6/5 → 领取1次 → 库存52/51 → 接受订单9 → 明确「进行中」 → 等待60秒。详见 [进度与证据](./PROGRESS_2026-10-15.md)。

保留现有Maa UI模板，不另写UI框架。复用现有模板、OCR与业务规则；CLI继续用于调试，Agent只做接入与结果转换。

目标调用关系：现有UI → Maa任务 → Python Agent → CLI与Agent共用业务函数 → FramePool截图 / 安全PostMessage点击。

## 第一步：订单扫描

先提取可复用的扫描入口，再注册CustomAction；不从CustomAction启动整个CLI子进程。

- 允许打开告示牌、切普通订单、逐个选卡和勾选「完成3次」；先验证勾选，再读数量。
- 输出9个订单的产品、库存/要求、差额及最小差额目标；鱼肉订单标记忽略。
- 不接受、不更换订单、不免费加速、不排产；当前CLI扫描包含恢复动作，不能不加区分地当作该入口。
- 复用UI已有controller与resource，不新建第二套连接，不依赖上次运行的latest文件。
- 每次点击、循环与等待之间检查停止；取消后不再发出新的点击。回调内识别使用Context接口，避免向同一运行中的Tasker再排阻塞任务。

验收：先模拟证明上述禁止动作不发生，再实机与CLI同帧结果对照；UI开始/停止有效，微信前台时点击前停止，鼠标与前台保持不变。

## 第二步：提交足数订单

- 在第一步的实时结果上逐项确认足数，只提交一单；原有「进行中」确认与睡觉提示处理复用，不按按钮消失判断成功。
- 区分已接受、已有进行中订单、无可执行订单、失败和取消；「已接受」不代表订单已完成领奖。
- 60秒等待改成可取消等待；不能在UI回调里用不可中断的长等待。

验收：足数与不足两种分支；重复运行不重复提交；确认「进行中」；等待期间停止有效。

## 第三步：实验性补产循环

仅在前两步通过后接入。先限定已验证的小麦单槽路径，保留一次性计划、不覆盖未知员工计划、按最新缺口排产与 `left >= right` 领取规则。

周期入口必须先执行 `ConfirmProductionCycleStart`：每次启动确认一次土地已手动清空，不放在每名员工/每轮循环里，也不缓存到下次启动。动作和pipeline节点已实现，CLI已复用该确认；目前interface未配置Agent/周期入口，Maa UI尚未接线实测。弹窗默认取消；Maa停止状态在弹窗前后检查，弹窗本身仍需用户关闭。

2026-10-15领取安全修复：移除“按钮持续可见/横幅”授权收取与`open_plan`自动收取；严格核对目标分母并连续两帧达标，只发一次领取。收取结果不明时停止，不进行自动补点或计划重置。监控要求一次性计划明确清空，不能把OCR失败当作清空证据。上述为模拟回归通过，改动后的完整路径仍需实机验收。

验收：连续两轮无需人工介入；中途停止不重置计划，恢复先读状态而非重新排产；最后完成/领奖状态必须单独验证。牧场补料未验收前不并入此入口。

## 上线前必须解决的接口约束

- **输入**：已验证的是渲染子窗口PostMessage。现有UI导航任务仍可走Maa原生Click/Scroll，不能宣称它们已通过不抢前台测试；新业务入口统一走安全输入，不借用这些原生动作节点。
- **前台**：微信主窗口在前台时子窗口点击仍有激活风险，现有保护在发送前停止，不主动切焦点。
- **停止**：`run_short_cycle.py`当前同步子进程不是UI停止方案；先抽共享函数与协作取消，不直接包一层CustomAction。
- **资源**：本次offset=0；非零偏移与运行态目录重建另验，不能用验收探针绕过就声称正式入口已通过。
- **运行环境**：本机已验证`.venv` MaaFw 5.13.1 x64；现有deps原生包为ARM64。必须验证UI、Agent与原生库架构/版本组合，不能混用后直接发布。
- **打包**：`tools/install.py`当前未复制`tools/`和`assets/catalog/`；接入后只打包静态业务依赖、模板和名称/能力库，不携带latest库存、历史截图或调试日志。
- **资源释放**：截图与识别结果只保留当前任务所需数据；正常、异常、取消均释放引用。不为UI长期保留每帧截图；日志/临时截图沿用项目缓存清理边界，另做持续运行观测。
