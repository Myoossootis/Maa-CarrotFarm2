# Maa 单次手动种植接入

2026-10-19：本次只修改代码、配置和离线测试，没有连接游戏控制器、发送游戏输入、启动 Maa 队列或开启连续循环。

## 入口和数量

新增独立任务 **手动种植（单次）**，默认不勾选。保留原 **手动种植（只读预检）**；数据窗口和预检 CLI 仍不执行。
两个入口共用农田1–3、12种普通作物、1–36格的选项。数量表示物理格数，不乘以6，并受实际空位限制。
修改源配置后需下次重新加载 Maa 配置；本轮没有重启或启动现有 Maa。

新入口 `ManualPlantingOnce` → 可取消工作进程 `ui_worker.py run_manual_planting.py --apply`。
只有这个明确执行入口传入 `--apply`；直接运行脚本且不传此参数仍只预检。
任务无后继、无错误重跑节点，一次请求完成指定格数后结束，不收获、不清地、不换员工、不定时重种。

## 前后校验与防重复

1. 在共享 `cycle_lock` 内读取新快照，检查版本、完整槽位、员工争用、空位、作物解锁、费用，以及全区域“一键种植”已关闭。
2. 检查目标槽位有画面映射，再定位农田、打开空位种子栏、选作物；名称、页码、选中边框、场景位移和空地遮挡都须确认。
3. 每一格操作前重新解码，与该格计划绑定状态比较；不会因计划失效改种别处。
4. 点击前用独占创建文件并 `fsync` 写下槽位防重复记录。键由建筑UID、载体UID、槽位和原始四元组组成，改变缓存序列、作物或数量不能绕过同一旧轮次的记录。
5. 只发送一次种植点击，随后有界地只读检查缓存。物理槽位未更新可继续等；有变化后必须立刻通过槽位、作物、轮次、员工和消耗检查。storageSequence 不保证随种植同步变化，仅作记录。矛盾状态或超时就停止，不补点。
6. 每格确认后才处理下一格，最后校验整批前后快照。部分成功、异常、取消或进程中断都会留下未确认批次；下一次入口会拒绝启动，不隐式续种。

记录在 `.tmp/manual_planting_execution/active.json`、`sent/*.json` 和按时间命名的证据目录（计划、前后快照、逐格快照、结果）。
未确认记录需要结合实际解码状态人工核对；没有自动删除记录或“失败重试”开关。

## 定位覆盖和实际限制

画面映射文件 `assets/catalog/manual_planting_ui.json` 已覆盖**农田1、2、3各15个几何位置**，农田2、3已接入同一个单次执行流程。农田3在保存快照中只拥有6格，预检仍只允许这6格，不会点击后面的未购买位置。

农田2、3使用包87明确配置的 `farmland2` prefab，槽位顺序不同于农田1；按各自地图锚点投影，使用历史画面的14个独立地块中心交叉核对，最大偏差6.817像素（阈值8像素）。同时增加西侧参考画面，定位时统一换算到同一地图坐标；固定HUD被屏蔽，多个视图结论矛盾即停止。详见 [定位校准记录](MANUAL_PLANTING_CALIBRATION_2026-10-19.md)。

农田1第1格、农田2第1格、农田3第1格番茄均已分别完成真实种植验收。农田2先确认成功，再种农田3；详情见 [农田2、3实机记录](MANUAL_PLANTING_23_LIVE_ACCEPTANCE_2026-10-19.md)。其他槽位、多格与种子翻页仍属于静态/离线验证。

场景定位接受720×1358、包87的已匹配地图，默认入口自动匹配标准缩放与本次验收的约5/7缩放，允许经过确认的平移；其他缩放、陌生画面、匹配歧义或角色遮挡会停止。不会从任意弹窗自动恢复。种子栏先关闭才拖动地图，避免选种状态下拖动导致批量播种。

种子栏关闭使用远离所有映射地块中心、颜色与纹理确认的空白道路/草地，点击后再次确认关闭；不再点击无关闭效果的底部提示文字。空白区域检查与目标槽位定位均使用同一完整缩放变换。本次验收的临时缩放校准已正式接入，详见 [默认入口缩放适配](MANUAL_PLANTING_SCALE_INTEGRATION.md)。

保持既有费用预检：当前缓存金币余额未知，收费作物仍会阻断；番茄配置0金币可通过该项检查。未将缺失余额当作0或足够。
