# 默认单次种植入口的缩放适配

本轮只修改代码、资源和离线测试。没有连接游戏控制器、读取新游戏画面、执行游戏操作或开启连续循环。

## 默认流程

`ManualPlantingOnce` → `run_manual_planting.py` → `ManualPlantingUI` 现直接加载4张参考图：标准比例两张，以及上次实机验收的5/7比例两张。农田、作物、数量选项保持原样，无需缩放选项或临时脚本覆盖。

新增资源：

- `farm_scaled_reference.png`：上次验收开始时的保存画面，使用农田2验收的两参考图交叉校准矩阵。
- `farm_scaled_west_reference.png`：上次农田3开始种植前的保存画面，使用西侧参考的120内点、88.24%内点比例校准矩阵。

矩阵、原截图SHA256和拟合证据保存在 `assets/catalog/manual_planting_geometry.json`，重建工具会将其写入 `manual_planting_ui.json`。运行时仅加载这些已核对的参考与矩阵，不拟合任意新缩放，也不依赖 `.tmp` 中的验收脚本或图片。

每个画面仍须通过原有原比例特征匹配：至少60个一致位移特征、足够空间覆盖、位移优势、残差以及缩放/旋转检查。匹配到5/7原生参考后，将参考自身的完整地图矩阵与本次画面的平移组合，再计算地块坐标。不会把5/7矩阵再次作用到已经变换过的槽位坐标。
多张参考结果须在整个映射范围内相符，最大位置差超过4像素就停止。旧的仅平移接口保留，并拒绝将缩放矩阵误用为平移量。

所有槽位共用规范地图坐标；`target`、`prepare`、种子栏关闭的地块避让均使用同一变换。地图平移后重新定位，定位失败时不会使用上次坐标继续点击。

## 校验与操作边界

操作前后的完整解码比较、逐格确认、未确认时停止、输入前独占落盘、防重复轮次记录与取消处理保持原实现。只读预检入口仍只读；单次入口默认不勾选，仍没有连续循环。
本次只支持标准比例与已验收的约5/7比例。其他缩放和不匹配的地图风格继续阻断，未宣称支持任意缩放。

## 离线证据

先用上次真实种植点击前保存的两张画面复现旧默认入口的定位失败，再用新的默认资源和入口回放。
目标点以两次真实验收记录的种植输入坐标减去原有25像素避让量为依据；测试调用正式 `target`，没有临时修改 `profile` 中的槽位或注入会话矩阵。

结果在 `.tmp/manual_planting_scale/offline_validation.json`，包含逐格期望坐标、实际坐标、误差与使用的完整矩阵。此次回放只说明默认代码与历史画面一致，未重新实机种植。
相对于已验收点击记录，农田2、3目标点的回放偏差分别为0.133、0.130像素；这不是新的地图绝对精度测量。
测试还覆盖默认初始化加载、连续切换农田后坐标不漂移、固定HUD下的地图平移、缩放下关闭种子栏的地块避让、未知比例、陌生场景、参考冲突、非法矩阵及原有解码和防重复检查。

最终离线回归共82项通过：手动种植及定位49项、Maa集成16项、正式解码运行时17项。测试的输入后端均为模拟，未启动游戏任务。
